Battery guides

Know what to check before buying.

Three short guides to collecting useful information. These guides do not select a replacement or give installation instructions.

  • 1. Read the battery label
  • 2. Check physical details
  • 3. Separate a code from suitability

If information cannot be read or confirmed, record it as unknown. Do not dismantle or remove a battery to complete these notes; ask a qualified specialist if access is unsafe or uncertain.

1. Read the battery label

A useful enquiry starts with the exact manufacturer name and full model or part number. Keep any letters, spaces and suffixes in your notes rather than shortening the code.

Record the voltage, chemistry or technology wording and ratings exactly as printed. CCA describes cold-starting performance; Ah describes capacity under specified test conditions. They measure different characteristics, so one number cannot substitute for the other. A missing rating is an unknown, not a zero.

Keep label observations separate from catalogue information. If a seller’s listing differs, retain both descriptions and ask for clarification rather than choosing whichever supports a purchase.

Useful enquiry: “This is the full code on my label. These are the ratings I can read. The remaining details are unknown. What else do you need to identify it?”

Technical reference: Century Batteries: Understanding battery ratings.

2. Check physical details

A similar-looking case does not establish fitment. Manufacturer guidance treats battery size, terminal configuration, hold-down system and electrical specifications as separate selection checks.

When preparing an enquiry, gather available manufacturer specifications for length, width, case height and total height. Keep the measurement units and the source alongside each value. Do not assume a case-height figure includes the terminals.

Ask a supplier to confirm terminal type, positive and negative positions, restraint and clearance for the actual installation. A photograph should make the viewing direction clear; an ambiguous “left” or “right” description needs clarification.

Useful enquiry: “Can you confirm the dimensions, terminal layout and hold-down for my equipment, and tell me which checks remain unresolved?” Physical agreement alone does not confirm electrical or application compatibility.

Technical reference: Century Batteries: Hi Performance 4x4 battery selection guidance. Its vehicle guidance is not a universal fitment rule for every battery category.

3. Separate a code from suitability

Recognising a battery code answers an identity question. Whether that battery is suitable for your equipment is a different question. NewBatteries’ preliminary identification must not be treated as permission to buy or install.

Provide the equipment make, model, year and variant when available, along with the existing battery details and any known modifications. Ask the supplier to check the manufacturer’s requirements for the specific application.

For stop-start vehicles, confirm the required battery technology and whether replacement configuration is needed. Century advises that many stop-start vehicles need the new battery configured to their energy-management system. A matching code or similar dimensions does not resolve that requirement.

Useful enquiry: “Can you verify this exact product for my vehicle variant, including technology and any configuration requirements?” If the answer is incomplete or sources disagree, keep suitability unconfirmed.

Technical reference: Century Batteries FAQs: stop-start replacement configuration.
